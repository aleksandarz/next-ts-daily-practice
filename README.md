# Next.js Practice

A collection of projects and exercises built with Next.js to strengthen my skills in modern full-stack React development.

This repository includes practical work focused on:
- file-based routing
- server-side rendering (SSR)
- static site generation (SSG)
- API routes
- dynamic pages
- reusable components
- responsive layouts
- clean project structure

The goal of this repository is continuous learning through real-world examples and hands-on development with the Next.js framework.

## Tech Stack
- Next.js
- JavaScript/Typescript
- Tailwind CSS

## Purpose
This project showcases my progress in building scalable, performant, and SEO-friendly web applications using modern frontend technologies.
